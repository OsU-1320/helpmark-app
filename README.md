# ヘルプマークNET

ヘルプマークを持つ人が、駅や商業施設で、NFCタグにスマートフォンをかざすだけで、支援を求められる仕組みです。登録した支援者（パートナー）にだけ、限定の通知が届きます。

東京都オープンデータ・ハッカソン2026（テーマ：防災）への提出物として開発を始め、現在は、東京アプリなどに組み込める「ライブラリ」としての提供を目指して、開発を続けています。

## 現在の状況

**ソースコードは、公開に向けて、整備中です。** 公開の範囲（保存・暗号化・通知・本人確認を、差し替えられる形で提供する予定の部品）が決まりしだい、このリポジトリで公開します。

## 目指していること

- 支援者は、登録した人だけ。不特定多数には、通知しない。
- 位置情報や健康に関わる情報など、個人情報の扱いを最小限にする。
- 自治体のシステム（本人確認、通知、データベース）に合わせて、部品を差し替えられる。
