# ヘルプマークNET

ヘルプマークを持つ人が、駅や商業施設で、NFCタグにスマートフォンをかざすだけで、支援を求められる仕組みです。登録した支援者（パートナー）にだけ、限定の通知が届きます。

東京都オープンデータ・ハッカソン2026への提出物として開発を始め、現在は、東京アプリなどに組み込める「ライブラリ」としての提供を目指して、開発を続けています。

## ヘルプマークとは
- 東京都が作成した、援助が必要な方が援助を受けやすくなるためのマーク。
- 「義足や人工関節を使用している方、内部障害や難病の方、または妊娠初期の方など、外見からは分からなくても援助や配慮を必要としている方々が、周囲の方に配慮を必要としていることを知らせることで、援助を得やすくなるよう、作成したマークです。」（引用：東京都福祉局HP）

## 注目する課題
現在のヘルプマークは静的な意思表示に留まり、実際に支援を求めるためには声を出すか、誰かに気づいてもらうのを待つしかない。人によっては声すらも出せず、パニックでアプリ操作もままならない場合もある。
そんな時に、ワンタップで支援を呼べるような仕組みを提供するのがこのアプリである。

## 現在の状況

**ソースコードは、公開に向けて、整備中です。** 公開の範囲（保存・暗号化・通知・本人確認を、差し替えられる形で提供する予定の部品）が決まりしだい、このリポジトリで公開します。

## 目指していること

- パニックに陥った場合でもアプリが機能する設計
- 支援者は、登録した人だけ。不特定多数には、通知しない。
- 位置情報や健康に関わる情報など、個人情報の扱いを最小限にする。
- 自治体のシステム（本人確認、通知、データベース）に合わせて、部品を差し替えられる。
